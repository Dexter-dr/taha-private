TAHA PRIVATE — Numeric Lab
==========================

اجرا:
1) فایل ZIP را از حالت فشرده خارج کن.
2) برای پیش‌نمایش ساده، index.html را در مرورگر باز کن.
3) برای نصب PWA و استفاده آفلاین، فایل‌ها باید از یک آدرس HTTPS یا localhost سرو شوند؛ بازکردن مستقیم فایل، سرویس‌ورکر را فعال نمی‌کند.
4) در رایانه با Node.js می‌توانی در پوشه پروژه دستور زیر را اجرا کنی:
   npx serve .
   سپس آدرس localhost که نمایش داده می‌شود را باز کن.
5) برای دسترسی از گوشی، می‌توانی پوشه را روی یک سرویس میزبانی HTTPS قرار دهی. برای خصوصی‌بودن واقعی، سرویس میزبانی و احراز هویت سمت سرور لازم است.

ورود نمایشی:

هشدار امنیتی مهم:
این نمونه یک پروژه آموزشی فرانت‌اند است. نام کاربری و رمز در app.js قابل مشاهده‌اند و قفل سمت مرورگر امنیت واقعی ایجاد نمی‌کند. برای داده‌های حساس یا انتشار عمومی، احراز هویت سمت سرور لازم است. رمز را برای حساب‌های دیگر استفاده نکن.
